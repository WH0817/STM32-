# STM32-
本项目是一个基于 STM32F103 系列单片机的智能寻迹小车设计，实现了红外循迹与超声波避障两种核心功能
项目功能说明
小车在正常运行状态下通过红外传感器阵列检测地面黑色轨迹，根据不同传感器输出组合实时调整左右电机转速，从而实现稳定的循迹行驶。当超声波模块检测到前方障碍物距离小于设定阈值时，小车立即停止前进，通过舵机驱动超声波传感器分别检测左侧与右侧空间，根据测距结果选择合适的转向方向完成避障，若三向均存在障碍则执行掉头操作。通过软硬件协同设计，小车能够在复杂环境下完成连续循迹与避障动作。
硬件组成说明
本系统以 STM32F103C8T6 单片机为主控核心，外围硬件主要包括红外寻迹模块、超声波测距模块、电机驱动模块和直流减速电机。红外寻迹模块由四个 TCRT5000 反射式红外传感器构成，用于检测黑白轨迹差异；超声波避障模块采用 HC-SR04 超声波传感器，并配合 SG90 舵机实现多方向测距；电机驱动部分使用 TB6612 双 H 桥驱动芯片，完成电机正反转及 PWM 调速控制。系统整体供电采用 5V 输入，经稳压后为单片机提供 3.3V 工作电压。
软件设计与运行逻辑
软件部分基于 C 语言编写，使用 Keil MDK 作为开发与调试环境。系统上电后首先完成 GPIO、定时器、PWM 以及外设模块的初始化，随后进入主循环。在主循环中，小车持续进行红外循迹判断，同时周期性触发超声波测距任务。当检测到障碍物时，循迹逻辑暂时挂起，优先执行避障流程；避障完成后系统自动恢复循迹模式。通过模块化程序结构设计，红外寻迹、超声波测距与电机控制彼此独立，便于后续功能扩展与算法优化。
